Autonomous Vehicle Using Reinforcement Learning

Project Overview

This project explores the development of an autonomous vehicle in a simulated environment using Unity, C#, and Reinforcement Learning.

The vehicle learns to navigate a simulated road environment while responding to traffic conditions, pedestrians, traffic signals, and surrounding objects.

The project was originally developed as part of my MSc Artificial Intelligence and Robotics with Advanced Research at the University of Hertfordshire (2023).

Technologies Used

- Unity 3D
- C#
- Reinforcement Learning
- Q-Learning
- Unity ML-Agents
- Visual Studio

Key Features

- Autonomous vehicle simulation
- Q-Learning-based decision-making
- Simulated road environment
- Pedestrian interaction
- Traffic signal detection and response
- Vehicle sensors and obstacle awareness
- Autonomous navigation

Project Objectives

1. Explore reinforcement learning for autonomous driving.
2. Develop an intelligent vehicle agent.
3. Simulate realistic road scenarios.
4. Investigate decision-making in dynamic environments.
5. Understand how AI can support autonomous vehicle systems.

Future Development

I aim to extend this project by introducing:

- Multiple autonomous vehicles
- Multi-agent reinforcement learning
- Advanced traffic scenarios
- LiDAR and camera sensor simulation
- Weather conditions
- Performance monitoring and analytics dashboard

My Role

I designed and developed this academic project using Unity and C#, implementing reinforcement learning concepts to explore autonomous vehicle behaviour in a simulated environment.

Project Status

Currently revisiting and improving the original MSc project to develop a more advanced autonomous vehicle simulation portfolio.
